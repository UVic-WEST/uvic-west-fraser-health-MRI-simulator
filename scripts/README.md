# Scripts
This folder contains scripts for system configuration/testing on the Raspberry Pi. 

## Setup
On the Raspberry Pi, in `~/uvic-west-fraser-health-MRI-simulator/scripts`, run:
```bash
# Make scripts executable
chmod +x launcher.sh
chmod +x fullscreen.py
chmod +x autostart

# Move to appropriate locations
mv launcher.sh ~
mv fullscreen.py ~
mv autostart ~/.config/labwc
```
